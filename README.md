# Monster Bot - بوت فيسبوك ماسنجر احترافي

بوت فيسبوك ماسنجر احترافي باللغة العربية يعتمد على مكتبة `fca-unofficial` (FB-Chat-API / Mirai Framework)، مصمم للعمل 24/7 مع ميزات حماية متقدمة.

## الميزات

*   **تسجيل الدخول الآمن**: يعتمد على ملف `appstate.json` (الكوكيز) لتسجيل الدخول.
*   **هيكلية منظمة**: ملفات `index.js` للتشغيل الأساسي، `main.js` لإدارة الأوامر، ومجلد `commands/` للأوامر العامة وأوامر المطور.
*   **حماية متقدمة**: يتضمن آليات لحماية البوت من الحظر وحماية المجموعة (Anti-Out, Anti-Change Name, Anti-Change Admin).
*   **تقييد الأوامر**: أوامر المطور متاحة للمطور فقط (عبر `ownerID`).
*   **استضافة 24/7**: مجهز للعمل على استضافات مثل Rawily مع خادم Express بسيط لمنع التوقف.

## المتطلبات

*   Node.js (الإصدار 16 أو أحدث مستحسن)
*   حساب فيسبوك لتشغيل البوت

## الإعداد والتشغيل

اتبع الخطوات التالية لإعداد وتشغيل Monster Bot:

### 1. استنساخ المستودع (Clone the Repository)

```bash
git clone https://github.com/YOUR_USERNAME/monster-bot.git
cd monster-bot
```

### 2. تثبيت التبعيات (Install Dependencies)

```bash
npm install
```

### 3. الحصول على `appstate.json` (الكوكيز)

لتسجيل الدخول إلى فيسبوك، يحتاج البوت إلى ملف `appstate.json` الذي يحتوي على كوكيز حسابك. يمكنك الحصول عليه بالطرق التالية:

#### الطريقة الأولى: استخدام إضافة متصفح (موصى بها)

1.  قم بتثبيت إضافة متصفح مثل 
Cookie Editor` لمتصفحك (Chrome, Firefox, Edge).
2.  سجل الدخول إلى حسابك على فيسبوك في المتصفح.
3.  افتح أدوات المطور (عادةً بالضغط على `F12` أو `Ctrl+Shift+I` أو `Cmd+Option+I`).
4.  انتقل إلى علامة التبويب `Application` أو `Storage` ثم `Cookies`.
5.  ابحث عن الكوكيز المتعلقة بفيسبوك (عادةً `facebook.com`).
6.  ابحث عن خيار لتصدير الكوكيز كملف JSON. إذا لم يكن متاحًا مباشرة، يمكنك استخدام إضافة مثل `Cookie Editor` التي تسمح لك بتصدير الكوكيز كـ `appstate.json` أو `JSON`.
7.  احفظ الملف باسم `appstate.json` في المجلد الرئيسي للبوت (`monster-bot/`).

#### الطريقة الثانية: يدوياً (أقل تفضيلاً)

1.  سجل الدخول إلى حسابك على فيسبوك في المتصفح.
2.  افتح أدوات المطور (عادةً بالضغط على `F12`).
3.  انتقل إلى علامة التبويب `Network`.
4.  قم بتحديث الصفحة.
5.  ابحث عن طلب `https://www.facebook.com/api/graphql/` أو أي طلب آخر لـ Facebook.
6.  في قسم `Request Headers`، ابحث عن `cookie`.
7.  انسخ قيمة الكوكيز بالكامل.
8.  استخدم أداة عبر الإنترنت أو سكريبت لتحويل هذه الكوكيز إلى تنسيق `appstate.json` المطلوب بواسطة مكتبة FCA. (هذه الطريقة أكثر تعقيدًا وتتطلب معرفة برمجية).

### 4. تحديد معرف المطور (Owner ID)

افتح ملف `main.js` وقم بتعديل السطر التالي:

```javascript
let ownerID = "YOUR_OWNER_ID"; // استبدل هذا بمعرف حسابك على فيسبوك
```

للحصول على معرف حسابك على فيسبوك (Facebook ID):

1.  انتقل إلى ملفك الشخصي على فيسبوك.
2.  انسخ الرابط (URL) الخاص بملفك الشخصي.
3.  استخدم موقعًا مثل `findmyfbid.com` أو `lookup-id.com` للصق الرابط والحصول على معرف حسابك الرقمي.

### 5. تشغيل البوت

بعد وضع ملف `appstate.json` وتحديد `ownerID`، يمكنك تشغيل البوت باستخدام الأمر التالي:

```bash
npm start
```

أو مباشرة:

```bash
node index.js
```

## الاستضافة على Rawily (أو أي استضافة تدعم Node.js)

لضمان عمل البوت 24/7، يمكنك استضافته على منصات مثل Rawily أو Replit. المشروع مجهز بخادم Express بسيط يقوم بالاستماع على منفذ (Port) لمنع الاستضافة من إيقاف البوت بسبب عدم وجود نشاط.

1.  **إنشاء مشروع جديد**: قم بإنشاء مشروع Node.js جديد على منصة الاستضافة التي تختارها.
2.  **رفع الملفات**: قم برفع جميع ملفات المشروع إلى مجلد المشروع الجديد.
3.  **تثبيت التبعيات**: عادةً ما تقوم منصات الاستضافة بتثبيت التبعيات تلقائيًا عند اكتشاف ملف `package.json`. إذا لم يحدث ذلك، استخدم الأمر `npm install` في Terminal الخاص بالاستضافة.
4.  **تحديد أمر التشغيل**: تأكد من أن أمر التشغيل هو `npm start` أو `node index.js`.
5.  **متغيرات البيئة**: إذا كانت منصة الاستضافة تدعم متغيرات البيئة، يمكنك تعيين `PORT` (على سبيل المثال، `PORT=3000`)، على الرغم من أن `index.js` يستخدم `process.env.PORT || 3000` تلقائيًا.
